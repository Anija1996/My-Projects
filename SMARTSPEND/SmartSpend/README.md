# SmartSpend — Personal Finance Tracker

A browser-based personal finance dashboard built with HTML, CSS, and vanilla JavaScript.

## Features
- Income and expense dashboard summaries
- Add, edit, and delete transactions
- Categories by transaction type
- Search, filter, and sort transactions
- Monthly expense summary and spending breakdown chart
- LocalStorage persistence
- Export transactions to CSV
- Responsive layout and form validation

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Add income and expense transactions.

No installation, server, or backend is required.

## Data storage note
Transactions are stored in the browser's LocalStorage on the current device and browser profile. This is persistence for convenience, not secure financial storage or cloud backup. Clearing browser site data can remove saved transactions. Do not enter bank passwords, card numbers, or other sensitive financial credentials.

## Files
- `index.html` — page structure
- `style.css` — layout and visual styling
- `script.js` — transaction logic, LocalStorage, filters, insights, and CSV export
